# C Programming

A collection of C programs from my previous semester, covering core C programming concepts, data handling, functions, pointers, strings, dynamic memory, searching, sorting, and small projects.

## Topics Covered

- C fundamentals
- Arrays
- Strings
- Functions
- Pointers
- Double pointers
- Dynamic memory allocation
- Searching algorithms
- Sorting algorithms
- Mini projects

## Repository Structure

- `01-basics` - Basic C programs and input/output
- `02-arrays` - Arrays and 2D array applications
- `03-strings` - String operations and character searching
- `04-functions` - Functions and parameter passing
- `05-pointers` - Pointers and double pointers
- `06-dynamic-memory` - Dynamic memory allocation using `malloc`
- `07-searching` - Searching algorithms
- `08-sorting` - Sorting algorithms
- `09-projects` - Larger practice programs

## How to Compile

Using GCC:

```bash
gcc filename.c -o program
./program
```

On Windows:

```bash
gcc filename.c -o program.exe
program.exe
```

These programs represent my C programming practice and learning progress. Some programs started as classroom or semester exercises and were cleaned up for this repository.
